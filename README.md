# Futurense Summer Bootcamp

A learning archive containing Python, SQL, NumPy, data-structure, and data-analysis exercises completed during a Futurense Technologies bootcamp.

## Why it matters

The repository records practical progress across the foundations needed for data and software work. It is organized as coursework rather than a single deployable application.

## Contents

- Daily Python exercises
- SQL scripts and database practice
- Jupyter notebooks
- NumPy and graph exercises
- Small problem-solving assignments

## How to use

Browse the files by date or topic. Python scripts can be run with `python <file>.py`, SQL files can be opened in a compatible database tool, and notebooks can be explored with Jupyter.
